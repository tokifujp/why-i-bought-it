# why-i-bought-it

ワシの購入履歴 ―「何を買ったか」ではなく「なぜ買う必要があったのか」から書く記録。

公開先： https://wibi.tokifuji.dev

## このリポジトリについて

買ったものの記録を記事として積み上げていく個人サイトのソースリポジトリ。
記事は Markdown で書き、このリポジトリの main ブランチへ push すると Cloudflare Pages に自動でデプロイされる。

## 記事の方針

- 記事の型は「なぜ必要だったか → どう選んだか → 使ってどうだったか」。後日、実際に使った場面での感想を追記することがある
- 書くのは、自分で買って、自分の生活や仕事で使ったものだけ。使っていないものの紹介や、メーカーのスペックを転載しただけの記事は書かない
- 合わなかったもの、失敗した買い物も書く。その場合は「なぜ合わなかったか」まで書く
- 視点は、車椅子ユーザーでありエンジニアでもある本人の、生活と仕事の文脈から。選定の基準そのものが記事の内容になる

## 表記ルール

- アフィリエイトリンクを含む記事には、その旨を記事内に明示する
- 提供や貸与を受けた物品について書く場合は、その旨を明示する（原則として、自分で購入したものだけを扱う）

## 扱わないもの

- 医療機器など、紹介や販売に法的な制限のあるもの
- 本人が使っていないもの、使う予定のないもの
